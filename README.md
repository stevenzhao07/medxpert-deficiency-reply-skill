## 这是什么？

收到审评机构的发补信，最头疼的不是"要补材料"，是**不知道审评员到底在问什么、怎么答才不会再发一轮**。

这个Skill帮你：
- 逐条拆解发补意见，翻译成大白话
- 给出每条的回复框架和要点
- 列出需要补充的材料清单
- 提醒回复时限和注意事项
