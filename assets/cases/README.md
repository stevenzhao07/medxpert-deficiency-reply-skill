## 案例标准结构

每个案例包含：

1. **案例背景**：什么产品、什么路径、什么情况
2. **发补意见原文**：审评员/审评机构怎么说的
3. **问题分析**：审评员真正关心什么、为什么发补
4. **正确回复思路**：应该怎么补
5. **教训**：怎么从一开始就避免
6. **关联检查项**：对应自查清单的哪一条
