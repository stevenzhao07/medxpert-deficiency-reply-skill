## 案例一：产品代码都可能搞错，凭记忆答题有多危险

### 一个真实的纠错过程

我们在搭建Skill骨架时，曾凭记忆把"骨科外固定支架"的FDA产品代码写成 **FRC**。

接入本机FDA全量分类数据库（7,088条device/classification）核对后发现：

| 代码 | 实际是什么 | 法规 |
|------|-----------|------|
| **FRC**（我们原来写的） | ❌ 生物指示剂（Indicator, Biological Sterilization Process） | 21 CFR 880.2800 |
| **NDK**（正确的） | ✅ 外固定支架系统（System, External Fixator, With Metallic Invasive Components） | 21 CFR 888.3040 |

**教训**：
- 即使是有经验的人、即使是AI，凭记忆给产品代码也可能张冠李戴
- 这就是为什么本Skill强制要求：**产品代码、法规号必须查权威数据库，不能凭记忆**
- 拿不准就标"待确认"，并引导用户用FDA Product Classification Database复核

> 这不是虚构的"AI会犯错"的故事——这是我们自己骨架里真实发生、被真实数据库抓出来的错误。

## 案例二：Zimmer外固定支架钻头 · 规格超差召回（Z-1532~1535-2009）

### 基本信息（FDA公开数据）

| 项 | 内容 |
|---|------|
| 召回编号 | Z-1532-2009 / Z-1533-2009 / Z-1534-2009 / Z-1535-2009 |
| 召回日期 | 2009-05-01 |
| 公司 | Zimmer Inc.（捷迈，骨科巨头） |
| 产品 | TransFx External Fixation System 钻头（2.0/2.5/3.0/3.5mm，多种规格） |
| 产品代码 | LXT |
| 根本原因分类 | Process control（过程控制） |
| 涉及数量 | 1206 + 1391 + 707 + 83 = 3,387件 |
| 分布范围 | 美国 + 澳大利亚、加拿大、萨尔瓦多、英国、德国、拉美、新加坡 |

### 召回原因（FDA原文）

> "Drill tip is out of specifications, reducing the efficiency of drilling action, requiring more force and potentially heating the bone surface during operation."

**翻译**：钻头尖端超规格，导致钻孔效率降低，需要施加更大力量，术中可能造成骨面发热。

### 这个案例的深层教训

1. **不是产品失效才召回**——钻头还能用，但性能偏离规格，可能导致骨热损伤，这是预防性召回
2. **骨科器械最怕"热损伤"**——钻头超差→需要更大力量→骨面发热→可能导致骨坏死，影响固定效果
3. **根本原因是过程控制（Process control）**——不是设计错，是制造过程没把规格控制住
4. **启示**：注册资料里的**性能测试和公差要求**，上市后必须持续保证；批量超差=召回

### 对应注册自查项

- 🔴 产品技术要求里的关键尺寸公差是否明确？
- 🔴 性能测试是否覆盖了"钻孔力/骨面温升"这类临床风险指标？
- 🔴 生产过程控制（SPC）是否能保证批量一致性？

## 案例三：Acumed腕关节外固定支架 · 零件无法组装（Z-1154-2010）

| 项 | 内容 |
|---|------|
| 召回编号 | Z-1154-2010 |
| 召回日期 | 2008-07-09 |
| 公司 | Acumed LLC |
| 产品 | Stableloc腕关节外固定支架系统，80套 |
| 产品代码 | JEC |
| 根本原因 | Process control（过程控制） |
| 分布 | 全球（美国、西班牙、日本、希腊） |

### 召回原因（FDA原文）

> "Parts are non-functional. The user is unable to fully pass the fixator pins through the body of the Stableloc assembly as required. The kit may also be missing the set screw."

**翻译**：零件无法使用——用户无法将固定针完全穿过固定器主体；套件还可能缺少紧定螺钉。

### 教训

1. **装配兼容性问题**：部件之间配合公差不对，针穿不过去
2. **还缺件（missing set screw）**：包装/装配过程的BOM核对失效
3. **根本原因还是过程控制**：来料+装配+成品检验环节没拦住

### 对应自查项

- 🔴 组件间配合尺寸是否做了装配验证？
- 🔴 成品包装的BOM齐套性检查有没有？
- 🔴 出厂检验是否包含"完整装配一次"的实测？

## 案例四：Sterilmed外固定装置 · 包装密封失效（Z-0556-2009）

| 项 | 内容 |
|---|------|
| 召回编号 | Z-0556-2009 |
| 召回日期 | 2008-08-08 |
| 公司 | Sterilmed Inc |
| 产品 | 外固定装置（独立包装），15件 |
| 产品代码 | KTT |
| 根本原因 | Packaging process control（包装过程控制） |

### 召回原因

部分独立包装袋的一端可能没有正确密封（pouches not properly sealed）。包装密封失效会导致无菌屏障破坏。

### 教训

- 无菌产品的**包装密封完整性**是召回高发点（全品类Top原因：Packaging相关占了近10%）
- 即使只有15件也要召回——无菌屏障失效是患者感染风险
